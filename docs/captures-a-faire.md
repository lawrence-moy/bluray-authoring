# Captures à faire

Liste des captures prévues dans le manuel, dans l'ordre des chapitres. Une fois une capture prête, placez-la dans `docs/img/` sous le nom indiqué, puis remplacez la note 📷 du chapitre par l'image : `![description](img/nom.png)`.

Conseils : un projet d'exemple assez riche (trois vidéos avec chapitres, deux langues, plusieurs pages, une jaquette remplie) ; thème et taille de fenêtre identiques pour toutes les captures ; PNG ; recadrer sur la partie utile quand la capture ne montre qu'une zone.
