# Manuel d'utilisation de bdauthor

bdauthor crée de vrais disques Blu-ray à menus (HDMV) à partir de vos vidéos : vous ajoutez les vidéos, leurs pistes audio, leurs sous-titres et leurs chapitres, vous dessinez les menus dans un éditeur visuel, puis bdauthor produit un dossier `BDMV` ou une image ISO prête à graver. Il dessine aussi la jaquette du boîtier et l'étiquette du disque.

> **Version de travail.** Ce manuel est une première version. Les emplacements marqués 📷 indiquent les captures d'écran à ajouter ; la liste complète est dans [captures-a-faire.md](captures-a-faire.md).

## En bref : de vos vidéos au disque

1. **Fichier › Nouveau projet**, puis **Ajouter des vidéos…** dans l'onglet **Vidéos**.
2. Pour chaque vidéo : titre, vignette, chapitres, pistes audio et sous-titres.
3. Onglet **Mise en page** : créez les pages de départ ou dessinez vos propres pages, puis testez-les avec **▶ Simuler la télécommande**.
4. **Édition › Vérifier les menus…** : corrigez les pages inaccessibles, vidéos jamais lancées, boutons injoignables.
5. **Édition › Projet…** : titre du disque, qualité d'encodage, disque visé, image ISO.
6. Onglet **Jaquette** : jaquette et étiquette, exportées en PDF ou en PNG.
7. **Édition › Générer le disque** : suivez la progression et lisez le rapport de vérification.
8. Testez le dossier produit dans un logiciel de lecture, puis gravez l'image ISO.
